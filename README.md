# Astronaut Character (feature/astronaut-character)

## Overview
In this branch, we'll implement the main astronaut character. This includes the character’s art, animations, movement mechanics, collision behaviors, and any special abilities that define the protagonist’s gameplay.

## Tasks & Milestones
1. **Character Assets & Artwork**
   - Import/Create the astronaut sprite or 2D model.
   - Ensure consistent visual style and scale in relation to the environment.

2. **Movement & Controls**
   - Implement vertical movement (launching upwards, possible mid-air controls).
   - Add horizontal or tilt-based controls for dodging obstacles and collecting items.
   - Ensure smooth transitions (idle, moving, landing, etc.).

3. **Collision & Physics**
   - Detect collisions with enemies, power-ups, obstacles.
   - Handle knockback or bounce effects (similar to Knightmare Tower).

4. **Animations**
   - Create states for idle, jump, fall, boost, collision reactions.
   - Integrate these in Unity's Animator or a simple sprite-based workflow.

5. **Polish & Testing**
   - Playtest character responsiveness and refine mechanics.
   - Optimize for performance on mobile devices.

## Additional Notes
- If referencing *Knightmare Tower*, incorporate a “bounce” attack or an upward thrust.
- Keep scripts modular for easy integration with other features (like enemies or UI).
