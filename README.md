# Enemies & Entities (feature/enemies-and-entities)

## Overview
This branch focuses on all in-game entities besides the main astronaut—enemies, obstacles, interactive objects, and environmental hazards. We'll define their behaviors, spawn logic, and animations/graphics.

## Tasks & Milestones
1. **Enemy/Obstacle Types**
   - Create basic placeholders (e.g., floating debris, alien drones, spikes).
   - Define their movement patterns (stationary, left-right drift, homing, etc.).

2. **Spawning & Difficulty Progression**
   - Integrate or extend procedural generation to spawn enemies/entities at intervals.
   - Adjust difficulty over time (faster spawn rates, new enemy types, etc.).

3. **Collision & Interaction Logic**
   - Define how enemies deal damage or interact with the astronaut (knockback, health drain).
   - Implement any special mechanics (e.g., shield-breaking, homing missiles).

4. **Visuals & Animation**
   - Add animations for enemy idle, movement, attacks, destruction.
   - Ensure consistent art style across different enemies/entities.

5. **Testing & Balancing**
   - Playtest spawn rates, difficulty, and damage values.
   - Adjust speed, health, and spawn frequency for a fun challenge without frustration.

## Additional Notes
- Keep scripts flexible so adding new enemy types later is simpler.
- Coordinate with the **UI/HUD** branch for displaying enemy health or special warnings if needed.
