# UI & HUD (feature/ui-hud)

## Overview
This branch manages the user interface and heads-up display, including menus, status indicators, in-game overlays, and any other on-screen elements the player interacts with.

## Tasks & Milestones
1. **Main Menu & Navigation**
   - Title screen, play button, settings menu, and links to store/upgrades.
   - Provide clear transitions between menu, game scene, and game-over screen.

2. **HUD Elements**
   - Display current score, health/fuel, power-up indicators.
   - Use minimal screen real estate to avoid obstructing gameplay.

3. **Pause & Game-Over Screens**
   - Implement a pause menu (resume, main menu, or quit).
   - Show final score, rewards earned, and option to restart on game-over.

4. **Visual Consistency**
   - Maintain consistent fonts, color schemes, and icon styles.
   - Align with the overall space/futuristic theme.

5. **Optimization & Responsiveness**
   - Ensure the UI scales properly across various Android screen sizes.
   - Test and refine input handling for phones vs. tablets.

## Additional Notes
- Coordinate with the **store** branch for purchasing/upgrading logic.
- Use Unity’s Canvas system or TextMesh Pro for sharper text (Also please look at assetstore for variety).
- Dark themed (Maybe little white stars behind) title screen with visible colors of buttons preferable.
